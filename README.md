reflexion
Configurar correctamente el entorno de desarrollo antes de iniciar un proyecto permite reducir problemas que podrían aparecer posteriormente durante la programación.
En primer lugar, disponer de un editor configurado facilita escribir y organizar los archivos. En segundo lugar, las extensiones de formato y análisis ayudan
a mantener una calidad mínima del código. En tercer lugar, Git permite conservar un historial de cambios y recuperar estados anteriores cuando es necesario. 
También es importante definir una estructura de carpetas desde el comienzo para evitar mezclar recursos y dificultar el mantenimiento.
La configuración de Node.js y Vite facilita trabajar con herramientas modernas y obtener retroalimentación rápida durante el desarrollo Otro aspecto importante es
verificar que las versiones de las herramientas sean compatibles. Durante la configuración pueden aparecer dificultades relacionadas con rutas, permisos, extensiones
o comandos de terminal. Estas dificultades pueden resolverse consultando la documentación oficial y comprobando paso a paso cada configuración.
Finalmente, un entorno bien preparado permite concentrarse en la construcción de la solución en lugar de resolver constantemente problemas básicos de configuración.
